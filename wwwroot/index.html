🌐 局域网主机 IP / 访问地址设置

在 Docker 容器化部署或通过 localhost 访问时，指定您电脑/NAS 的真实局域网 IP（如 192.168.10.2）或域名。配置后，所有 M3U 播放列表与单流链接将自动生成该地址，方便 TV、Jellyfin 和手机一键直连。

🔑 Jellyfin / IPTV 播放令牌

播放令牌独立于网页登录会话，Jellyfin 不会因管理员退出或登录过期而断开。新生成的令牌为纯 6 位数字，错误尝试会触发临时锁定；服务端仅保存摘要和管理员密码加密后的恢复密文。

关闭后 M3U、HLS 和分片地址不再携带或校验令牌，仅建议完全不对公网开放服务的用户使用。
